ตัวอย่างหน้าจอที่เสนอ

ภาพร่างหน้าจอเพื่อใช้หารือกับเจ้าของระบบ ประกอบการพิจารณาแผนทำให้ระบบธนโชคพร้อมใช้งานบน Production

ฉบับร่างเพื่อหารือ 3 หน้าจอตัวอย่าง อ้างอิงจากรีวิวความพร้อม Production ยังไม่ใช่ข้อสรุปการออกแบบ

อ่านก่อน — หน้าจอเหล่านี้เป็นภาพร่างเพื่อให้เห็นภาพร่วมกันเท่านั้น ข้อมูลที่แสดงเป็นตัวอย่างสมมติทั้งหมด ไม่ใช่ข้อมูลจริงของลูกค้า ทุกส่วนปรับเปลี่ยนได้ตามความเห็นของเจ้าของระบบ

หน้าจอเหล่านี้ตอบช่องว่างอะไร

ไม่มีการเฝ้าระวังและแจ้งเตือน

ปัจจุบันหากงานส่งข้อมูลล้มเหลว จะทราบก็ต่อเมื่อผู้ใช้แจ้ง — หน้าจอที่ 3 ทำให้เห็นผลทุกรอบและแจ้งเตือนอัตโนมัติ

ตรวจสอบย้อนหลังได้ยาก

ยังไม่มีมุมมองรวมว่าใครทำรายการอะไรเมื่อใด — หน้าจอที่ 2 แสดงประวัติธุรกรรมรายผู้ถือสลากพร้อมผู้ทำรายการ

ไม่มีภาพรวมสถานะระบบ

ผู้ดูแลไม่มีจุดเดียวที่เห็นสถานะงานประจำวัน — หน้าจอที่ 1 รวมตัวเลขสำคัญและสถานะงานไว้หน้าเดียว

C

ตั้งได้ว่าจะแจ้งใครเมื่อไหร่ — เจ้าของระบบกำหนดผู้รับผิดชอบได้เอง ไม่ต้องพึ่งทีมพัฒนา

สิ่งที่อยากได้ความเห็นจากเจ้าของระบบ

  1. หน้าจอเหล่านี้ครอบคลุมงานที่ใช้จริงหรือยัง — ขาดงานสำคัญอะไรไปบ้าง
  2. ตัวเลขสี่ค่าบนหน้าภาพรวม ตรงกับสิ่งที่ต้องดูทุกวันหรือไม่ ถ้าไม่ ควรเป็นค่าใด
  3. การแจ้งเตือนควรส่งถึงใคร และช่วงเวลาใดที่ต้องแจ้งทันที
  4. ข้อมูลใดบ้างที่ห้ามแสดงบนหน้าจอ หรือต้องจำกัดตามสิทธิ์ผู้ใช้
  5. ลำดับความสำคัญ — ถ้าทำได้ทีละหน้าจอ ควรเริ่มจากหน้าใดก่อน
